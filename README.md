# RMail

Легковесный desktop-клиент электронной почты на Rust, Tauri 2 и React.

## Статус

Рабочий MVP с локальным SQLite-кешем, защищённым хранилищем паролей и IMAP-подключением. Объём первой версии описан в [docs/mvp.md](docs/mvp.md).

## Стек

- Rust + Tauri 2
- React 19 + TypeScript 7 + Vite
- shadcn/ui + Tailwind CSS

## Реализовано

- Трёхпанельный интерфейс: папки, список писем и чтение сообщения.
- Изменяемая ширина панелей и доступные tooltip-действия.
- Поиск по локальному кешу писем, выбор письма и окно создания письма.
- Единые theme tokens, light-first дизайн и базовые пустые состояния.
- Onboarding первого аккаунта с локальным хранением метаданных в SQLite.
- Проверка IMAP по TLS и SMTP через обязательный STARTTLS: аутентификация, список папок и SMTP NOOP без отправки писем; понятные безопасные подсказки для ошибок сети, TLS и учётных данных.
- Tauri-команды для создания, списка аккаунтов и проверки подключения, покрытые unit-тестами валидации.
- Первая IMAP-синхронизация: список папок и до 50 последних сообщений INBOX в локальный SQLite-кеш, который отображается в интерфейсе.
- MIME-разбор выбранного письма: безопасное отображение `text/plain`, локальный кеш body и метаданные вложений.
- Санитизированный `text/html` доступен по переключателю в sandboxed iframe; скрипты, формы и внешние медиа удаляются до рендеринга.
- Вложения сохраняются только по явному действию пользователя: системный диалог выбирает место, файл заново извлекается по IMAP и создаётся без перезаписи существующего.
- Создание plain-text писем: локальное сохранение черновика и отправка через SMTP STARTTLS после явного подтверждения пользователя. Исходящие вложения будут добавлены отдельным этапом.

## Данные и безопасность

SQLite хранит только название аккаунта, адрес и IMAP/SMTP-хосты. После успешной проверки пароль почты сохраняется в Stronghold, а не в SQLite или логах. Пароль хранилища задаёт пользователь, и его нельзя восстановить.

Tauri Stronghold подготовлен для credentials: vault защищается Argon2-ключом, а salt и зашифрованный vault находятся в app data. Доступ к плагину ограничен явной capability `stronghold:default`.

### Linux build note

Stronghold использует `libsodium`. В `.cargo/config.toml` зафиксирован поддерживаемый флаг `SODIUM_DISABLE_PIE=1`, который предотвращает ошибку линковки SIMD-символов в WSLg/Linux-среде.

## Разработка

Требуются актуальные Node.js и Rust.

```bash
npm install
npm run tauri dev
```

Проверки перед изменениями:

```bash
npm run lint
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
```

## Принципы

- Быстрый запуск и локальный кеш.
- Минимальный, доступный desktop-интерфейс.
- Секреты не попадают в логи или локальную базу данных.
